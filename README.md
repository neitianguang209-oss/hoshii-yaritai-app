# ほしい・やりたい

欲しいもの・効率化したいことを低摩擦に記録し、必要な場面で引き出すための個人用アプリ。

## 構成

- React 18 + htm（ビルド不要、esm.sh経由のCDN import map）
- データ保存: Supabase（Claudeとのチャットからも直接INSERTできるようにするため）
- PWA対応（manifest.json / sw.js）

## カテゴリー

1. **欲しいもの**
   - 日用品ストック: 場所タグ（スーパー/ドンキ等、プリセット＋自由入力）のみで管理。買ったらチェックでアーカイブ。
   - 欲しいものリスト: 即決型／出会い待ち型の二値。金額は任意項目。
2. **効率化したいこと**
   - 進捗（未着手/進行中/完了）× 重要度（高/中/低）。完了は削除せず保持。
   - 週次カウント（**日曜始まり**）: その週に完了した件数を自動集計して表示。

## ローカル起動

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:5505 を開く（launch.json名: `hoshii-yaritai`）。

## Supabase

`supabase/schema.sql` にテーブル定義とRLSポリシーをまとめている。認証なしの個人利用アプリのため、
RLSは「anonキーを持つ全員に許可」という最小限の設定（データは公開URLの推測困難性のみで守られる）。

## iPhoneへの追加

1. 公開URLを **Safari** で開く（Chromeでは「ホーム画面に追加」がPWAとして機能しない）
2. 共有ボタン → 「ホーム画面に追加」
3. 以後はホーム画面のアイコンから全画面アプリとして起動する
